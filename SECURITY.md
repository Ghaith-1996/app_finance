# Security Policy

## Supported versions

Pulsefolio is a hosted application. Only the currently deployed production version (built from
the `main` branch) receives security fixes; older commits and forks are not supported.

## Reporting a vulnerability

Email **ghaith.alali1996@gmail.com** with the subject line `Pulsefolio security report`.

Please include:

- the affected URL, route, or file;
- steps to reproduce, and the impact you observed;
- any proof-of-concept request or code (redact other people's data).

Please do **not** open a public GitHub issue or discussion for a security problem, and do not
disclose it publicly until a fix has been released.

You will receive an acknowledgement by email, and we will keep you informed while the issue is
investigated and fixed.

## Testing guidelines

When investigating, please:

- use only accounts and data you own;
- do not access, modify, or delete other users' data;
- do not run denial-of-service, spam, or load tests, and do not send SMS or email to numbers or
  addresses you do not control;
- do not attempt social engineering or physical attacks.
